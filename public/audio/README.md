# Radio

Drop MP3 files named `radio-1.mp3` and `radio-2.mp3` in here and the in-game
radio will play them on a loop, at the volume set in Settings.

With no files present the game runs a small generative station instead — a slow
warm arpeggio synthesised in the Web Audio graph. That is the default, and it is
why the game ships with no audio downloads at all: every other sound in Tiny
Convoy (engine, tyres, wind, hitch rattle, impacts, interface) is synthesised
live from the simulation rather than played back from a file.

Nothing here is required. The directory is intentionally empty.
